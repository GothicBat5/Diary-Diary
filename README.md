# Halcyon-Diary 
### Diary-Diary

> [!TIP]
> A personal diary web application designed to provide a space for recording thoughts.

## Tiny Overview:
**Halcyon-Diary** is a web-based diary project focused on the personal journaling experience; 
an opportunity to explore how interactive web can be as well as using it as personal writings.

## Project Structure:

- `art/` — Art assets and visual resources, the CSS page.
- `auxiliary/` — Supporting files and utilities.
- `behavior/` — The JS page where interaction made possible.
- `photo/` — Images and Photographs.
- `index.html` — Main entry point of the application.
- `author.html` — Author-related stuff .
- `notebook.html` — The notebook interface.
